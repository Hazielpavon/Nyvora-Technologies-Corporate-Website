# Security Policy

## Scope

This policy covers the Nyvora Technologies corporate website contained in this repository, including its public pages and contact endpoint. It does not describe or publish the private Nyvora Myke application, runtime or internal architecture.

If you are unsure whether a finding belongs to this website, report it privately and identify the affected URL or repository path.

## Reporting a vulnerability

Send suspected security issues privately to [support@nyvoratechnologies.com](mailto:support@nyvoratechnologies.com). Do not open a public GitHub issue for an unpatched vulnerability.

Include only the information needed to understand and reproduce the issue:

- the affected URL, route or file;
- a concise description of the behavior and potential impact;
- reproducible steps using non-sensitive test data;
- relevant browser, operating system or request details;
- sanitized screenshots or logs, when useful;
- a safe way to contact you for follow-up.

Do not include passwords, API keys, financial information, customer records, production message content or other personal or confidential data. Do not perform destructive testing, access data that does not belong to you, interrupt service or send automated traffic that could affect availability.

## Handling reports

Nyvora Technologies will review reports according to available resources and the information provided. This policy does not promise a response or resolution time, continuous monitoring, compensation or a bug bounty. Any remediation and disclosure timing will depend on the finding, affected systems and required coordination.

General product questions and support requests may use the same address, but should be clearly labeled so they can be routed appropriately.

## Supported version

Security fixes are applied to the current maintained version of the corporate website. Older commits and third-party services may no longer represent the deployed configuration. Vercel, Resend, DNS and email-provider issues are also subject to the respective provider's security and support processes.
